# Meet File Peek

A little room to read your files. Now powered by Rust. 🦀

Open a Markdown document and see the formatted page immediately. Headings, tables, lists, links and code blocks all have a place.

## Open it your way

- **Drop a file** onto the window or the app icon.
- **Press ⌘O** to choose a file.
- In Finder, use **Open With → File Peek**.

PDFs, images and other supported documents use your Mac's built-in Quick Look preview.

## Make Markdown a double-click away

1. Select a `.md` file in Finder and press **⌘I**.
2. Under **Open with**, choose **File Peek**.
3. Click **Change All…**.

## A few useful keys

| Action | Shortcut |
| --- | --- |
| Open a file | ⌘O |
| Preview / source | ⌘E |
| Reload after a change | ⌘R |
| Larger / smaller text | ⌘+ / ⌘− |
| Reset text size | ⌘0 |

> Your files stay yours. File Peek opens them read-only.
